# 計測の一覧

この道具について、何を測ったか、数字がどこにあるか、何をまだ測って
いないかを、1 か所にまとめます。数字の表そのものは、それぞれの文書に
あります。ここには、条件と主な値だけを写しています。食い違っていたら、
リンク先の文書が正です。

確度の表記: 【実測】手元で測った / 【未確認】確かめていない。

## 先に結論

- 測ったのは、部品ごとの性質です。索引づくりの時間と大きさ、検索 1 回の
  時間、粗い判定での当たりの割合、Copilot CLI で仕組みが通ること【実測】
- 題材は、公開されているコード(O3DE)と、合成のコーパス
  (`tests/fixtures`)だけです
- 続けるかを決めるための比較(実コーパスで、既存の手順と同じ質問で
  比べる)は、まだ行っていません。しきい値の合否は、どれも出ていません

## しきい値と、いまの状況

しきい値は、[evaluation-data-spec.md](evaluation-data-spec.md) の
「Decision thresholds」が正です。

| 条件 | いまの状況 |
| --- | --- |
| 上位 5 件に根拠の passage がある質問が 80% 以上 | 未判定。行の範囲で注釈した正解が、まだ無い。公開されているコードでの粗い判定の値は、下の「検索の当たり」 |
| 回答の合格率が 80% 以上 | 未計測。採点した回答が無い |
| 検索時間の p95 が 3 秒以下 | 実コーパスでは未判定。公開されているコードの約 7 万 passage では、hybrid で 27.8 ミリ秒(索引とモデルを読み込んだ後) |
| 既存の手順より品質を下げず、時間か費用の中央値が 20% 以上下がる | 未計測。既存の手順(`agent_grep`)と候補の手法を、同じ質問で比べていない |

## 共通の条件

- PC: Windows 11、16 コアの CPU。GPU は使っていない
- 埋め込みモデル: 断りが無ければ `intfloat/multilingual-e5-small`
- 公開されているコード: C++ のゲームエンジン O3DE の一部。測ったときの版
  (コミット)は、文書に残していない
- 合成のコーパス: `tests/fixtures`(13 ファイル。日本語の文書を含む)
- エージェント: GitHub Copilot CLI 1.0.112。モデルは Claude Haiku 5.5
  (自分のキーで使う設定)
- 数字を文書に入れた日: 2026-11-16

## 数字の限界

- 質問は 9〜15 件です。差は目安で、統計として言い切れるものではありません
- 公開されているコードでの当たりの判定は、上に書いたとおり粗いものです
- 描画まわりの 12 問と合成のコーパスは、既定の対応表から一般の語を外すか
  どうかを決めるのに使いました。その分の偏りがあります
- 大きいほうの索引づくりは、ほかの作業と並行でした。単独なら、もう少し
  速いはずです
- Copilot CLI の実行は、形ごとに 1〜2 回です。どの形が安いか・速いかは
  言えません。0.1 の 3 回目は、渡した道具の一式がほかの回と違うので、
  入力トークンを比べられません
- 質問の一覧と、1 回ごとの結果は、このリポジトリに入れていません。同じ
  数字を出し直すには、同じ質問が要ります

## まだ測っていないもの

実コーパスでの比較(README の計画の手順 4)は、全体がまだです。手順は
[comparison-runbook.md](comparison-runbook.md) にあります。

- 質問 20〜30 件と、行の範囲で注釈した正解(調整用に、別に 5〜10 件)
- 検索だけの手法(keyword・semantic・hybrid)の、当たりの割合と検索時間
- 既存の手順(`agent_grep`)と `agent_cf` を、同じ質問で 3 回ずつ
- 回答の採点と、しきい値の合否

ほかに、確かめていないもの:

- `agent_grep_cxxref`(cxxref と比べる手法)。一度も実行していない
- `--no-custom-instructions` を付けた実行。`--dry-run` で、オプションが
  渡ることだけを確かめた
- `--add-dir` で渡したフォルダの指示のファイルが、読まれるか【未確認】
- 約 7 万 passage を超える規模での、総当たりの検索時間
- 大きい埋め込みモデルで、日本語だけの質問が良くなるか【未確認】
- GPU を使ったときの速さ【未確認】。スレッドやプロセスを増やしても速く
  ならない原因【未確認】
- アプリ、対話のセッション、Claude Haiku 5.5 のほかのモデル、Visual Studio
  Code([copilot.md](copilot.md) の「確かめていないこと」)
